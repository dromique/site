# Showcase Portfolio

## Over dit project
Dit project is mijn persoonlijke **showcase portfolio**, ontwikkeld in **Next.js**, **Tailwind CSS** **React** en **GSAP**.  
Het doel van dit portfolio is om mijn projecten, skills en creativiteit te tonen aan potentiële stagebegeleiders en werkgevers.  

Het project bevat:
- Projectcards met Links naar het desbetreffende project.
- Responsive design dat geschikt is voor desktop en mobiel.
- Een rustige, gezellige "cozy autumn" stijl voor sfeer.
- Roodborstje dat in de header op en neer hopt.
- Vogelgefluit wat afspeelt door op 'Ik kan fluiten!' te klikken.
- Muzieknoten die uit de snavel van het roodborstje komen tijdens het zingen.

## Technologieën
- **Next.js** – Framework voor React-gebaseerde webapplicaties.
- **Tailwind CSS** – Utility-first CSS framework voor snelle styling.
- **React & GSAP** – Animaties en transitions voor interactieve elementen.
- **VS Code** – Ontwikkelomgeving.

## Installatie
1. Clone de repository:
git clone https://github.com/dromique/site.git
2. Installeer de dependencies:
npm install
3. Start de ontwikkelserver:
npm run dev
4. Open vervolgens in je browser:
http://localhost:3000

## Hoe het werkt
- De Home page toont een overzicht van mijn CV en cards met projecten waar ik aan heb gewerkt.
- Animaties zijn toegevoegd met GSAP voor soepele overgangen en visuele dynamiek.
- Styling en responsive layout zijn gerealiseerd met Tailwind CSS.
- De site is gebouwd in Next.js en draait lokaal via npm run dev.

## Interactieve Elementen
- Een roodborstje hopt op en neer in de header.
- Het roodborstje beweegt zijn snavel en vleugels op en neer.
- In de header een knop om het roodborstje te laten fluiten.
- Er komen muzieknoten uit de snavel van het roodborstje.
- De noten animeren omhoog met een natuurlijke zweefbeweging en fade-out effect.
